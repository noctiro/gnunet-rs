# Caller-driven official SETI client

`Client::new_set(instance, source, limits, create_until)` owns one set MQ. Drive it until the CREATE `Written` observation; then `add`, `evaluate` and `accept` queue original commands. ADD and CREATE have no service ACK. Only an RESULT carries FAILURE/DONE or an element. Result frames and `current_size` remain unchanged, not a claim that this adapter computed or verified the intersection.

`Client::new_listener` owns a separate finite listener intent. Each `Incoming` binds original source allocation, epoch and one non-Clone suggestion. Accept may use a different set MQ and canonical clock; the suggestion lifetime is checked in its original listener clock domain. Source loss before full ACCEPT writing cancels that original attempt. Dropping/expiring a suggestion causes REJECT on the next listener drive. Original context storage is shared through the private input lease, and metadata/payload admission is bounded. Caller-retained received objects remain caller-owned memory.

Cancellation removes only wholly unwritten originals. Partial suffix and CANCEL drain on the same MQ with a hard bound no later than original expiry+grace. The resulting `CancelSubmitted` is local writing, not a remote ACK or DONE. Actual source loss closes first, settles original operations as Unsent/Unknown and never reconstructs a set or replays ADD/EVALUATE/ACCEPT. Listener-only explicit `reconnect_listener` restores the original finite listen intent with a new epoch; old inputs stay invalid even if the raw incoming id repeats.

`Limits.result_layout` explicitly selects Packed20 or Aligned24 (native default). The pinned C RESULT u64 lacks packing. `Limits.element_type_order` separately selects correct network order (Rust-provider default) or the known native C producer's omitted htons. Raw bytes and raw decoded fields are always available; neither profile is inferred from message contents. A local unchanged-C-header sizeof/offsetof probe confirms Aligned24 on the current host, not full C-service interoperability.

Native polling is isolated in client/io.rs over the common CLIENT/channel/framing/clock ports. There are no algorithms, service/CADET host, implicit Resolver, hidden thread, disk worker or FFI dependencies. Pending input expiry retires its alarm target before polling the next one; retained full RX cannot starve queued REJECT/CANCEL writes. Source-clock failures return their error after closing the affected set owner; the original listener remains independently caller-driven for rejection/cleanup.

One local Unix IPC model covers original wire failure, local full CANCEL, drop/expiry REJECT, distinct clock domains, stale incoming rejection and listener reconnect. Its controlled actor emits only explicit failures and does not fabricate successful set computation, authenticated peer traffic or complete GNUnet interoperation. Native SETI service/CADET composition and C counterparts still require implementation/integration.
