# Shared Resolver verification maintenance

`verify.py` consumes a complete repository, never a synthesized subset workspace. It copies every source/settings/lock file (excluding `.git`, build targets and Python caches) to `<output>/workspace`, checks addition/deletion/byte equality, and compares Cargo package roles and local type identities before/after relocation. Both the main workspace and noalloc workspace metadata are read with `--offline --locked`; both locks and the whole inherited lint table are preserved. All compilation uses output-local targets. A foreign local manifest or duplicated local package name is refused.

Default `--package` is this tool's package parent. It must be the repository's canonical broker path. Outputs must be disjoint from the repository, upstream and all normal receipt directories. `--profile native-retry` is the default current M14 inventory. Explicit `clock-source` supports the reviewed M13 source tree only; profiles never silently downgrade and an unexpected added/deleted/renamed test or target refuses validation. An optional `--overlay-manifest` accepts only the exact six reviewed native-retry Rust paths with baseline/candidate SHA checks; Cargo/settings/locks can never be overlaid. The integrated workspace needs no overlay.

`witnesses.json` is a reviewed per-file/per-name inventory, not evidence of functionality. Native-retry groups are Broker41, Resolver core39, IPC56, ARM endpoint27 (old19 plus logical/physical clock7 and its existing library unit1), and ARM core32. The original two Delivery doctests and two Delivery UI controls remain. Canonical clock ownership adds three exact UI negatives and a positive; all rlibs are selected from Cargo JSON artifacts bound to the expected manifest and package ID. Existing external-component tests are listed as such, never reported executed by this component.

All Python guard assertions are explicit `if/raise`, including the nested IP-denial Python program; Python `-O` cannot remove them. All 15 original pure controls remain, plus a optimized child decoding a malformed official header and six workspace/artifact identity controls. The maintained gate requires all 22 exact test method names and successful unittest summary. Embedded C template values were preserved.

Use all normal build arguments shown by `--help`. `--preflight` performs only complete copying, role metadata, both-lock/settings checks, pinned clean upstream and existing normal receipt/file validation, and the 22 controls. It returns `preflight_passed` with zero Rust tests and zero actors: it is not a full successful verification. No code compilation, C builder or socket/daemon actor is started in that mode.

Full mode retains all original nine profiles/eighteen C/R actors, the normal Resolver daemon, both extracted source components, and the two original Delivery UI checks. Literal-peer, component and normal-daemon evidence remain separate. Existing normal builds are historical receipts whose declared binaries/libraries/headers/compile configs are hash-checked; recorded historical builder SHAs are not attributed to today's Python source and no rebuild of the old library is claimed. Fresh public C callers still use compile flags and the same fixed source path. Both source-components' C template strings remain unchanged.

A fresh full-chain run against current workspace inputs is still required before any functional acceptance. No owner status is automatically promoted.
