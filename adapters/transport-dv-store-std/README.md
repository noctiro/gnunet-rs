# Durable public DV watermarks

`Provider::open(absolute_dedicated_directory, Limits { records })` uses the shared marker-qualified `Namespace::TransportDv` Store and exactly one bounded Worker. This namespace has its own marker, lock, image magic, filename and temporary-file prefix; existing namespace identities, including the T1 monotime file, remain unchanged. An existing directory must carry this exact marker; unmarked or foreign stores are refused. The caller supplies an independent owned directory and the shared backend's ordinary parent-path/race preconditions. No C data or private key is imported.

The provider reuses bounded snapshot recovery, original writer ownership, checksums, atomic file replacement, file/directory sync, readback, generation checks and the Unknown fence. It adds no second directory wrapper, lock protocol, worker or per-packet filesystem validation layer. Loads observe the catalog from the recovered or definitely committed snapshot. They are not new disk reads or invented worker-load operations. A pending/unobserved/unknown mutation blocks such loads.

The official subsystem is `transport`. `Kind::Learn` stores `transport-dv-learn-monotonic-time` for the initiator; `Kind::Box` stores `transport-backchannel-monotonic-time` for the actually decrypted and verified sender. Their source-monotonic values are independent of UTC and each other. The bounded internal image uses GNDVM001, count/reserved fields and unique ordered kind/peer/stamp records. This is a private Rust storage format, not a wire extension. Full capacity refuses new forever watermarks without evicting any existing one.

`Request::from(SourceWork)` retains the original LEARN SourceId. BOX requests retain the original crypto Task token. These are caller metadata declarations, not authenticated or durable proofs. Operations have a private provider domain and checked serial. Only original Worker completion with matching Job, namespace and next generation can update the catalog and create a private `Persisted` receipt. Queue admission does not do so. Equal already durable values return `Known` with the previous recovery/commit Evidence and no fabricated new job, avoiding per-packet fsync for a reused BOX epoch.

Cancellation suppresses the original callback while retaining filesystem debt. Unknown outcomes fence the provider and are never automatically replayed. Shutdown drains outcomes and joins the original worker, preserving the first cause and independent join validation/errors. Synchronous filesystem calls retain their ordinary blocking contract; no native deadline is represented as a forced disk rollback. No independent File-drop close errno is fabricated.

The provider's public LEARN load/commit application checks the original pure source id. The BOX admission glue below is implemented; Engine/native scheduling remains separate work. Durable stamps reject older epochs after recovery; they do not persist nonce history or prevent equal-stamp replay across restart. Live nonce replay admission remains separate.

## BOX durable/live admission glue

`box_admission::start(&mut Provider, actual Opened, Bounds)` takes only private authentic AEAD/signature output. `Bounds::new(shared_actual_RuntimeClock, original_native_Instant)` retains the caller's original process clock and absolute hard target; it never derives a later relative deadline. Caller must use the same clock/target as original packet admission. The Opened's original logical/source Task remains authoritative. Bounds reserves one bounded clock subscription; native hard guard/alarm precedes canonical sampling and revision-race waits. Logical/native/clock failures latch and cannot be revived by rollback. Sleep/subscription ownership stays inside the returned state across canceled caller poll futures. No hidden task is created.

Start actually calls Provider.load(Box(originalTask,sender)), verifies private Loaded domain/request/namespace, and compares the sender watermark. Lower packet stamps refuse. Equal values actually go through Provider.store's private Known fact, without inventing a worker job. Higher/absent values actually submit the original Box request to the shared Provider and retain the original Opened, store Operation, Worker Job and loadedGen+1 expectation in Waiting. No plaintext/payload clone occurs. Request identity uses sender/stamp/target/Task/encapsulation/nonce from the authentic owner, never an untrusted outer sender claim or arbitrary u64 verified constructor.

Waiting exposes its original operation/job and `poll_expired(cx, provider)`; caller polls it beside Provider events. Expiry or cancel invokes only the original local callback cancellation and retains/report its exact disk debt. It never retracts an admitted fsync/rename. `observe(self, provider, &Event)` borrows the event; unrelated events return Unrelated with the unchanged wait. Only a private Persisted matching original operation, Job/domain, namespace, generation, stamp and canceled=false becomes Ready. Actual matching failure/Unknown/end/expiry never gives a grant and never replays a store.

Ready.grant performs a fresh SAME-provider load immediately before every live replay attempt. This closes the stale-ready race: Ready10 cannot pass while higher11 is pending/unknown, or after it committed. A newer snapshot for another peer is allowed only when this sender still has the exact durable stamp. Original private persisted/load proof and all original packet/context/time fields are rechecked, then Replay.admit is called. Only a private-constructor Granted combines durable proof, fresh current load, original Bounds and live Admitted; a bare pure Admitted cannot be wrapped into a false durable grant. Granted.message() checks original bounds and authentic/replay source on every borrow. Ready and Granted also expose poll_expired for caller-owned Engine-capacity waits. A post-replay expiry erases/recycles the output and returns Closed while conservatively retaining the nonce record, never an expired grant.

Only current-store preadmission WouldBlock retains a retriable Ready or allows Refused.retry with the same original Bounds/task and no store debt. Terminal canceled/expired/Unknown/replay failures never expose their old Opened for reauthorization. Reattempting a Ready grant does only a fresh read, never another original store mutation. `Refused` preserves first cause plus independent cancel outcome and original debt metadata.

All Waiting/Ready/Granted/Refused states have consuming recycle paths built on the separately frozen whole-loan Opened/Admitted hooks. Waiting.recycle(provider) first attempts original cancellation and returns the exact operation/job/cancel tombstone; Provider must still drain/join it. Closed waits return None because a prior Refused already owns the loan. Ready revokes local ungranted authority; Granted consumes live/crypto authority; neither pretends to finish Engine/FC/write work. `Recycled::into_parts` returns only the fully erased original mutable loan and historical Binding/reason/debt metadata, never an Opened or another grant. Original ciphertext nonce history is not undone.

Caller integration sequence: own fixed original frame/FC leases, construct original Bounds, perform crypto opening, call start, drive original Provider events + Waiting/Ready expiry, grant with the original live Replay, and feed Granted.message() to the Engine/native admission only under its independent capacity/write receipts. The containing owner maintains original Task→frame/FC-debt mapping; recycling or durable/replay grant never acknowledges physical MQ/flow-control delivery. Provider and one worker remain independently owned and must actually poll/drain/join even after payload recycle.

This layer deliberately preserves the live/cross-restart boundary: a durable stamp rejects lower epochs, equal stamps remain legal, and exact nonce history is live only. It adds no nonce disk protocol or cross-restart equal-packet guarantee. Engine/native scheduling remains to be connected. Synchronous clock/catalog/provider calls retain their ordinary blocking contract; the gate classifies expiry after such a call returns and never claims it force-interrupted the call.
