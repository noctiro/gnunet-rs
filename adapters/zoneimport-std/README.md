# Online zone importer host

This caller-polled host consumes the actual `gnunet-zoneimport-core` actions through existing IDENTITY, NAMESTORE and DNSSTUB clients. The standard PROGRAM, input readiness, selected Reporter, shared Resolver and seventeen-coordinate STATISTICS publisher are supplied by the separate `gnunet-zoneimport` app. No service, background task, OS resolver, thread or worker is hidden here.

`finish_input` records genuine caller EOF and activates the lazy IDENTITY monitor. It does not fabricate an inventory END. Only initial IDENTITY END, retained key material and completed inventory registration permit `Core::finish_inventory` followed by `Core::finish_input`. Non-DNS ego names are diagnosed and ignored. Ambiguous canonical names are never assigned an arbitrary private key or replaced by a new CREATE.

Each Core job retains its original native operation or DNS request, source epoch and fixed canonical/native bounds. Original native admission is recorded after that mapping exists. Actual whole frame write only marks local byte exposure. CREATE and STORE success use their original service result; local/partial/unknown mutation results do not replay. A complete parent lookup is distinct from negative/backend/source failure: only its records reach `delegation_observed`; failure uses clock-free `delegation_failed`. Existing exact-suffix egos remain independent anchors as decided by Core; this host adds no parent-graph policy.

DNS packets remain unverified. A raw callback must belong to the same active RequestId and configured upstream; the complete inspector then checks original DNS ID, QR/opcode and original IN/NS question. TC needs the whole original matching question but may have truncated RR data. It switches to a numeric TCP connection with the same query bytes, server and original fixed hard; TCP capacity waiting never renews it. Complete final NOERROR responses alone reach conversion and an owned whole-record-set replacement. NXDOMAIN, other RCODEs, malformed packets and unsupported-only data do not become empty deletions. Extended RCODE stays u16. Genuine empty NOERROR is distinct. Expired matching records are observed once before conversion. FOREVER minimum/refresh values are data; all request and source initialization budgets stay finite.

The original general IDENTITY and NAMESTORE clients reconnect with their own backoff after EOF, IO loss or retirement expiry. Every old operation first retains and publishes its original local certainty/exposure and cause; no unknown CREATE, delegation or STORE is replayed. Unaffected names and later independent work continue on fresh epochs. The initial inventory still has its one original hard bound; an already active inventory is not rebuilt or re-seeded after reconnection. Protocol, resource and clock/Resolver/CLIENT failures remain fatal. An explicit `reconnect: false` policy retains fail-first behavior. A CREATE native hard retires that same source immediately, then only permits independent later CREATE work to reconnect.

Dedicated cache iterators use START/NEXT whole-write credit. Actual END gives Complete. Source failure closes that exact cursor, retains its cause and reports Failed/Incomplete; already observed prefix records remain available to Core while unseen names query DNS. No synthetic END/NEXT or snapshot completion is minted.

Buffers and rows have explicit bounds. The complete DNS byte/name arena and converter storage are reused. Per-packet typed parser slots and final serialized record sets allocate fallibly under configured limits; no typed borrowed packet survives into another receive or await. Outstanding owned answer storage is bounded by Core jobs. No full backup or record payload is formatted in diagnostics. All counter overflow is diagnostic saturation, never a business failure. Absolute SET metrics include the official cumulative per-run totals at indices2,3,16; the cache-credit coordinate reports outstanding whole-written iterator credits.

`poll_native_guard` precedes canonical waits and is disabled after `begin_close`. `poll` rotates clients, cursors, UDP, TCP and Core admission rather than draining one ready source indefinitely. `begin_close` physically closes those same original owners, then `poll_close` consumes original terminal facts and Core retirement without a clock sample. The caller supplies its one fixed cleanup hard and continues the same Resolver. A stalled native-to-Core invariant retains original job/epoch/bounds/exposure and never claims Closed. `into_report` first closes any still-live originals, then consumes observations; it does not grant quiescence. Source/local errors have separate bounded retained slots and explicit overflow counts. Core latches pre-stop business failures once and records terminal CREATE/parent-STORE rejections on the original bounded zone row, including replies drained after stop. The terminal report refreshes both failed and uncertain input totals through close; known-unsent normal cancellation does not become a business failure, and zero totals do not assert that every input was stored. There is no worker in this host, so no thread join is substituted by Drop or timeout.
