# Round2 original native flow

`Round2` consumes `CompletedRound1`: first-round material and the still
live original PILS signing owner. It opens the second CONSENSUS MQ with the
original SID, midpoint, roster and final deadline. No client/identity epoch or
phase target is silently renewed.

Own production, remote validation and original source work alternate under
finite units; PILS observation precedes them. Temporary borrowed context
lets both validators use the same original keys/roster without copying the
polynomial, keypair or another transcript owner. The owned producer keeps each
original slot and returns a refusal for missing keys or an unrepresentable
original1024-bit FAIR response.

The original identity and exact SIGN operation are matched against whole
write and signature completion. After independent signature verification the
same validation kernel checks own and remote bytes: shape, identity, purpose22,
Round1 opening, all original-index polynomial/FAIR equations and local recovery.
Only the original matching INSERT whole-write commits the own contribution;
CONCLUDE does not stand in for that fact. No local523 is fabricated. The public
source sum type retains remote observation or own SIGN/INSERT
provenance with branded operation IDs.

While one remote observation is held, guarded transmit-only SDK progress keeps
JOIN/INSERT/CONCLUDE moving without reading a second frame or adding a hidden
queue. Early523 is legal after whole JOIN. Premature525 still cannot certify an
unwritten524. Invalid/old-context input cannot reserve or revoke an accepted row.

Completion requires the whole JOIN, own INSERT and CONCLUDE, real525 and
closed CONSENSUS plus the physically retired/idle persistent PILS client. Its
original Round1 report and second-round signature/source facts transfer once.
Foreign completions retain their object but do not erase an original
operation's unknown-result classification. Failure/cancel retain original
causes and partial writes, close sources first and erase owned secrets.

The finalizer keeps original roster/threshold/index/evidence, aggregates complete
contributions and writes standard783 through canonical shared codecs. Empty,
insufficient or local-nonmember results remain distinct from a usable decryption
Roster. Generally usable FAIR and full unchanged-C generation interoperability
remain unachieved; source wiring and scoped tests cannot supply that credit.
