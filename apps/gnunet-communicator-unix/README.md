# gnunet-communicator-unix

PROGRAM foreground for the installed official testing-only UNIX communicator. Configure `[communicator-unix] UNIXPATH` using a fresh caller-owned filename; existing names are refused. `USERNAME` uses shared privilege/NSS handling before reactor/native construction. `MAX_QUEUE_LENGTH` bounds original incoming callback debts (Rust default64, official C default8000; explicit configured values supported up to65535). The normal `transport`, `pils`, `statistics`, and `resolver` selectors use the same process configuration/clock/explicit Resolver broker. Startup captures parent FD ownership, rejects unexpected inherited listener resources, and registers parent/OS signal sources.

`[communicator-unix-rust]` offers MAX_QUEUES(default256), OUTPUT_FRAMES(8), OUTPUT_BYTES(524280), IO_SLICE_BYTES(65535), DATAGRAM_BYTES(OS profile), SOCKET_BUFFER_BYTES(1048576), OPERATION_LIFETIME(30s), QUEUE_IDLE_TIMEOUT(5min), DAEMON_LIFETIME(1day), STARTUP_TIMEOUT(30s), and ENOBUFS_RETRY(1ms). The node-wide `[PILS] PROFILE` selects `reference029` (also `reference-0.29.1`, the default) or the official conditional `deterministic` profile. Optional `[communicator-unix-rust] PILS_PROFILE` must agree with an explicit node choice; conflicts fail before native startup. Clock rollback never renews a native target. This finite source keeps the original bound Unix socket/PILS owner across recoverable TRANSPORT MQ loss, retires old callback/payload debt and reannounces live metadata after a fresh registration. Fatal provider/clock/protocol/native-socket errors still close the original runtime. Initial startup applies only until its first READY; reconnect never renews the process lifetime or existing queue/operation bounds.

READY follows public PILS identity and whole local registration/address writes; it says neither service ACK nor authenticated peer. SIGINT/SIGTERM and parent control cause physical original close, preserve source/cleanup failure reports and produce STOPPED with no remote delivery claim. The explicit PROGRAM task drives Runtime, the shared original-source statistics Producer and same Resolver fairly; no detached task or process-global pool is introduced. The Producer receives the exact same RuntimeClock Arc as that Resolver and Runtime selectors. Each original setter has its immutable native hard registered before canonical-clock/Resolver work. Whole local writes, permanent Loss/Unknown fencing, retired pending bytes and Destroyed metadata remain distinct in the retained report. No source is recreated to replay an uncertain counter delta.

The official nonpersistent C-UNIX metrics are `# queues active` (current queue inventory), `# bytes sent` (complete sendto bytes), `# network transmission failures` (failed native attempts), and `# transport transmission failures` (incoming debt failure). Existing `# invalid datagrams received`, `# incoming IPC frames written`, and `# actual incoming callbacks` remain explicitly Rust diagnostic counters. Their source is the original Runtime's saturating cumulative observations; these are lower bounds after saturation and never peer authentication or delivery receipts. Recovery events report exact old-source retirement and new-source publication, separately from delivery or authentication. Queue credit opens only after that source's whole SETUP write; pending old SENDs and callbacks are not replayed.

Any producer failure gates the next business poll and closes the original Runtime, keeping its first cause independent of Resolver/descriptor/path/stdout errors. Normal shutdown first physically closes that Runtime, then freezes its final snapshot including zero queue inventory and newly retired incoming debts. The same Producer and Resolver continue fair polling under one original5s native final bound; queued mutations are not treated as completed writes. Final publisher metadata and source counters are reported independently. PROGRAM cancellation and construction failures use caller-owned cleanup slots: immediate abort/Drop is recorded as retirement/Unknown, never as a successful drain, and original Resolver cleanup is retained even if the task was never polled.

Nonblocking I/O operations and finite resource debt are bounded; synchronous configuration/PROGRAM/NSS/path metadata/stdio/close calls retain their ordinary OS blocking contract, not a false force-interrupt guarantee. UNIX claimed identities are unauthenticated and this implementation does not qualify any CORE/UDP/DHT or other stopped transport scope.
