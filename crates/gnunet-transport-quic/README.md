# QUIC communicator application profiles

Default noalloc/no_std, with caller-provided frame/body slabs and fixed stream slots. This is application-byte/header parsing and bounded stream state. It implements neither QUIC/TLS nor HTTP3/QPACK and creates no placeholder runtime. The separate `gnunet-quic-communicator-host` runtime feeds selected ALPN, decoded headers, stream bytes/FIN and original stream callbacks to this layer.

`raw` matches the installed experimental `gnunet-communicator-quic` profile: ALPN candidates `hq-interop`, `hq-29`, `hq-28`, `hq-27`, `http/0.9` (historical names, without HTTP request syntax). The original initiator sends its naked32-byte PILS public peer proposal once on client bidirectional stream4, then a sequence of normal GNUnet BE16-size/type frames. The acceptor receives that claim and does not send a reciprocal identity; the initiator's expected peer comes from its original communicator queue request. Raw frame/identity parsing handles arbitrary partial reads; complete frames stay held under backpressure. Exact unconsumed suffix is returned. FIN on stream4 means connection shutdown; truncated identity/frame fails.

`h3` separately uses ALPN `h3` and decoded HTTP3 headers. Initiator's first bidi stream0 is POST `https`, path `/`, authority the original address, octet-stream body containing raw32 public identity. Subsequent POSTs carry one full GNUnet frame. GET requests have no body and allow server-to-client frames through response bodies; a POST200 response may also carry one queued frame, or be empty. GET timeout is204 with no body. The original client maintains16 GET long polls. Canonical request/response headers and decimal content lengths are written into bounded caller storage. Parsers accept the meaningful contract, not nghttp3 implementation flags. Per-stream assembly requires end-of-body, validates exact content length and one complete frame, and handles identity/message/empty responses separately. Following out-of-order streams cannot deliver a frame before the identity POST actually completes. `next_poll` is fair across finite original GET slots; replacement GET is an explicit new stream/token after the original response ends, never a continuation of its deadline.

Both public identity proposals are merely presumed sender metadata, consistent with the public communicator API. Neither source establishes a GNUnet identity signature or binds that identity to the TLS certificate. This library exports no authenticated-peer factory. It neither loads certificates nor touches keys. Real QUIC/TLS peer/session policy remains a separate runtime requirement.

`Instance` is a stable caller allocation domain using checked Cell counters, suitable for thread-confined noalloc owners and M0. Original Epoch/Stream tokens compare pointer, allocation and stream generation; callbacks cannot be rebound using only a reused numeric id. Every source/stream has a fixed finite monotonic bound, and time rollback is explicit TimeUncertain. Connection/source native deadlines must also be enforced by the native host before awaiting logical-clock work. Retirement/release is clock-free. Metadata release does not claim an stream reset/socket close. Body slabs are zeroized on reuse/drop; immutable TX buffers remain caller-owned.

`tx::Cursor` preserves immutable original plaintext and partial provider cursor. Provider acceptance is distinct from UDP exposure, QUIC ACK and remote application processing. Cancel before provider admission is Unsubmitted; positive admission remains ProviderAccepted and requires original stream reset/connection close with its independent outcome. No wire CANCEL or invented application ACK is added. Dropping an async waiter in the native runtime must keep these original owners/cursors.

The standard communicator IPC remains the existing shared codec: reliable communicator advertisement, queue setup/teardown and original1209/1204 packet lifecycle. Official C advertises queue MTU1000 (raw) /1080 (h3), with separate internal IPv4/IPv6 message limits1452/1232. The native runtime must respect its IPC/QUIC resources and preserve source/queue/FC generations. C receive callbacks pass NULL completion, i.e. no communicator receive-FC callback; a Rust owner can use the shared bounded FC path without inventing a private protocol. A local `consume` count merely reclaims body storage and may inform QUIC credit; it is not an IPC ACK. The pure layer performs no queue registration or send-success claim.

C assumptions that stream-read/DATA callbacks contain entire identity/frames, C MQ cancel assertions, ignored return values and unlimited internal queues are implementation defects/organization, not added wire requirements. Rust buffers are bounded and reusable; partial bytes and original deadlines survive. The mature stack must enforce stream-id uniqueness/HTTP3 pseudoheader/QPACK/TLS rules and perform reset, shutdown, queue teardown and independent error reporting. An original Connection cannot be resumed under a new source.

This package needs only existing gnunet-types/wire/zeroize dependencies and no registry additions. The public aggregate model is compile-checked with this layer during workspace admission and remains unexecuted.
