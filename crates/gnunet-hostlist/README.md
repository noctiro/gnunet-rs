# GNUnet HOSTLIST pure core

The active v0.29.1 daemon builds its client/server/daemon sources. `Advertisement` implements the CORE producer format, header type160 followed by URI bytes and a final NUL. It preserves the consumer's first-NUL/ignored-tail behavior. The unused C reserved-field structure is not emitted. New producers are canonical. `Frames` walks complete concatenated message frames in caller storage and never claims a frame is an authentic HELLO.

Default features are no_std/noalloc. The alloc feature provides `Core`, zeroizing/redacted shared `Uri`, checked domain-bound `Job`/immutable `Fetch`, bounded scheduling/quality/history, and `HelloFrame`. HELLO admission invokes existing `gnunet-hello` parsing and signature checking at the supplied time, retains exact original binary bytes, derives its official URI once, and preserves the selected `SignatureCoverage`. Default `Gnunet029` authenticates metadata only; addresses remain claims. No weaker-profile retry exists.

`Core::new` preallocates fixed URI and HELLO rows. Current binary-frame plus derived-URI allocation capacity is charged against `hello_bytes`; metadata has a separate row bound. At most `urls` accepted/configured rows and one bounded untested candidate exist. A candidate is tested separately, so a failed test preserves the current learned inventory. Actual successful complete HTTP/framing observations accept it; backend store counts remain separate. Scheduling alternates configured/learned sources fairly, bootstraps below four non-self CORE links, tests new advertisements at most once per three seconds, and doubles bounded retry history. There is one original active download job, never an unbounded operation list.

Historical learned URL/quality data restores no live source, HTTP result, signature verification, or callback authority. `finish` matches the original private job; `retire_without_time` can fail an original job without inventing a timestamp. Expired HELLOs are physically removed; logical rollback cannot revive them. A HELLO checked in a future logical sample is not retagged as a past check. Backend admission/HTTP/PEERSTORE/CORE effects are implemented by the separate native adapter.

One aggregate public pure framing/scheduling/allocation model is supplied as source. It uses public `.invalid` URI strings and metadata only, never keys, signature verification, hashing, storage or sockets. Native interoperability/full-node qualification are not claimed.
