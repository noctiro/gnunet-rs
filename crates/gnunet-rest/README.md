# GNUnet REST pure contracts

Default no_std/noalloc, caller-owned buffers. `http::Request::parse` checks one complete HTTP/1.0 or1.1 prefix, duplicate Content-Length/TE ambiguity, Host, line/header/body/chunk/total-wire quotas, chunk extensions/trailers, exact consumed length and validated body decoding. Truncated bytes remain on their original connection. `http::Response` preflights whole caller-buffer output, suppresses Content-Length on204, and closes the connection explicitly. No native I/O occurs here.

`route::resolve` enumerates built-in v0.29.1 routes; private GET `/sign` is registered by the IDENTITY plugin, credentials use singular `/reclaim/credential`, and there is no invented REST ticket-issue endpoint. `contracts` validates official IDENTITY, NAMESTORE five-flag record JSON and RECLAIM attribute/credential/ticket shapes using shared `gnunet-json`. `text` supplies bounded GNUnet Base32 text; unused pad bits must be zero. Query keys are unambiguous, decoded duplicate keys are refused, and explicit `Query::get_bytes` supports non-NUL raw signing data.

The router enumerates CONFIG/GNS and conditional JOSE OpenID endpoints, including `/jwks.json` outside `/openid`; it does not create their explicit host providers. There is no placeholder Other-family response. Unbuilt pabc_plugin.c is not registered. Namespace boundaries are checked; accidental C prefix aliases such as `/identityevil` are not recreated. Expect headers are explicitly rejected rather than waiting for a100-continue body. No HTTP/2, TLS, keepalive or upgrade owner is supplied; the active C server enables no TLS and Connection:close is valid HTTP/1.1. `form::Form` adds bounded URL-encoded and multipart/form-data field parsing with full preflight, original-body borrowing, finite work and duplicate requested-field rejection.

One public aggregate model source covers framing/pipeline boundaries, chunk decode, ambiguous length rejection, partial-body retention, routes/JSON fields, raw query decoding, Base32 and204 framing.

Optional `oidc` retains noalloc/caller-buffer operation and adds the purpose27 authorization artifact, exact ticket/length/list layout, strict signature/PKCE verification and opaque access-token encoding/decoding. Ticket is decoded before issuer derivation; URI hyphens remain intact; signature verification alone is explicitly not RP authorization, one-use/expiry checking or ticket consumption. Sensitive owned workspace is zeroized/redacted and output is atomic on validation/capacity/signature failure.
