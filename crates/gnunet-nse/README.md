# Pure NSE service engine

`gnunet::nse` supplies the allocation-free service owner, separate from
`gnunet::clients::nse` (subscription client) and the borrowed wire codecs. It
has no daemon, private key, runtime, proof-file descriptor or embedded Argon2
array. The host provides verified PILS identity announcements, original CORE
connections/subscribers, canonical logical times, optional jitter randomness,
PILS signing, borrowed PoW scratch and durability/native completions.

`owner::Service<P,S>` bounds peers and subscribers; history is the official64. Its exclusively borrowed non-ZST Instance brands every original effect. Immutable sign/transmit/notification snapshots prevent a late completion from
using a later identity, history slot, peer, subscriber or native stream. Equal
cancellation retains an issued signing tombstone until its original callback
terminates. Native hosts retain partial writes until completion or physical
retirement; a completion is local submission/capacity, never remote delivery. Identity change has an explicit retirement barrier; its token is not a physical
stream fence, backend quiescence proof or filesystem lock. The host must perform
those actions before committing a new validated announcement.

Crypto admission checks purpose14/60 and rawproof8+origin32 with exact salt16
`gnunet-nse-proof` (no extra NUL). Default work15 performs Argon2id and
EdDSA checks. Configured work0 explicitly skips authentication and gains none of
that security credit. Distance remains the origin's signed claim, as in the
reference verifier; local generation exposes its internal native-timestamp-byte
profile without adding any wire field. Counter enumeration is only an internal
search order. Work is caller-budgeted and never wraps a counter silently.

Current/previous/next handling, carryover, equal cancellation, lower pushback,
higher admission and ring wrap are semantic round transitions. Default delay
policy follows the normal C preprocessing (no RNG). Optional bounded
jitter is a distinct Rust scheduling policy, not a protocol negotiation. Source
statements behind an inactive CPP guard are not runtime compatibility evidence. Ranking distinguishes an absent qualified candidate from a score of zero. An unsigned local scheduling placeholder cannot exclude an admitted remote claim
until that exact local identity has its proof. This applies to current/previous
selection and next-round carryover. Once work completes, the now-qualified local
candidate competes with the current remote candidate; a better or equal remote
candidate stays selected. Existing immutable signing/transmission leases keep
their original bytes and epoch. This corrects candidate existence/eligibility,
without changing the history-count or statistical-summary policy. West weights are newest-first n+1..2, correction0.332747 and log2 peer floor;
one sample has legal NaN deviation, zero samples have deviation0. Pure libm
0.2.16/no-default handles standard floating functions. Checked linear statistics
conversion refuses overflow rather than reproducing an undefined C cast.

The separate `gnunet-nse-host` adapter supplies caller-driven native CORE/PILS
composition, shared runtime subscriber sockets, original physical retirement,
and a fenced raw8 proof-file backend with explicit failure recovery. `gnunet-service-nse` supplies official configuration, early activation/control
capture, configured account switching before runtime setup and shared Unix
credential admission. These native owners retain the pure engine's leases;
they introduce no private NSE protocol or production C dependency.

Acceptance remains scoped to each recorded run. Historical mixed C/Rust and
multihop evidence is described in its frozen audit and is not regenerated by
an admission change. Pure models, IPC snapshots, original-C expression oracles
and public crypto vectors alone do not establish a complete mixed-service node.

Every `now`, round and wire timestamp is official absolute UTC microseconds,
not a process elapsed counter. A native host should share the existing runtime's
absolute-UTC Clock/Deadline subscription and recheck the original target on
early completion or rollback, as the native adapter does. CORE self-loopback
contributes to the peer floor and SelfUpdate path; zero-peer models do not
establish that integration.

## NSE statistics observations

`metrics::Metrics` lives once on the unique `owner::Service`, as ten ordinary
u64 values and a permanent overflow/projection flag. The original marker-only
Instance and branded peer/effect tokens gain no Cell, atomic or sharing change. Seven counters are cumulative across peer recycling and identity changes
within that Service. The three gauges are the checked linear estimate from the
existing summary, connected peers (including CORE self-loopback), and
maximum admitted history hop count, reset/recomputed at the round boundary. A zero-history estimate uses the existing one-node floor. Projection overflow
preserves the last representable value and latches a diagnostic; it does not cast
an invalid float or affect signature/PoW/history authority.

recognized current-source floods count received; outside-round and lower
pushback classification count their original causes. A peer alarm that
cannot generate a flood records no-proof before lack-of-history as applicable. No event is invented merely to fill a C counter. Histogram-only `extra messages`
and `cross messages` are excluded from the ordinary ten official names.

A host calls `transmission_admitted` only after CORE send admission and
retaining the original SendId/source. The original Pending Send has one admitted
bit; duplicate/stale/unleased/foreign calls do not increment. Capacity refusal
and a held request retry do not count. The transmitted counter and hop-zero
started counter describe this local original submission attempt, not whole-write
or remote receipt. Original `transmitted` completion still independently settles
full local writes. The pinned C increments these counters in transmit_task
before submitting PILS signing and sends in the later signature callback; the
Rust admission boundary does not claim identical values for every intermediate
C cancellation/signing failure or scheduling instant.
